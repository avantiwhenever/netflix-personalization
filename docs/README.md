# Netflix MAPS-Inspired Artwork Personalization Demo

Inspired by Netflix's [MAPS: Multimodal Asset Personalization at Scale](https://netflixtechblog.com/maps-netflixs-multimodal-asset-personalization-at-scale-32f96320785e)
— personalizing which poster gets shown per title, using CLIP image
embeddings instead of ID-based interaction history.

**Not affiliated with Netflix.** Posters and metadata from [TMDB](https://www.themoviedb.org/).

Full source, data pipeline, and documentation (including an offline
validation of the ranking mechanism against popularity/random baselines):
https://github.com/avantiwhenever/netflix-personalization
